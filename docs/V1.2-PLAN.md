# HomeBot/HomeBot — Pre-Release Polish + v1.2 Creator Studio Plan

*Locked 2026-08-08 with Aden. Sequencing decision: major changes land NOW, before the public tag — not after release. The v1.1.0 tag moves to the end of Phase A.*

## Current architecture (surveyed @ `ce110d9`)

- Root package: `homebot-tool-registry` (SQLite-backed tool registry, ajv-validated schemas).
- `widget/`: the Electron app — electron-vite, React 18, Electron 28, electron-builder 24. Clean main/preload/renderer split, i18n, Jest + Playwright e2e.
- 89 renderer components incl. `ToolsPanel`, `SettingsPanel/Modal`, `TrustPanel`, `PermissionModal/History`, `WebServicesPanel`, `ImageGenerator`, `FirstRunModal`, `VoiceConversation`.
- ~31 main-process tools (`src/main/tools/`): filesystem, terminal, browser, email, calendar, crm, rag, vision, voice, etc.
- Installer: NSIS **one-click already configured** (`oneClick: true`, desktop + start-menu shortcuts, runAfterFinish; icon fixed in #88). Windows target.
- Privacy surfaces already exist: TrustPanel, permission requester + audit log — new cloud features must route through these, not around them.

## Phase A — Pre-release polish (blocks the v1.1.0 tag)

**A1. Tooltip system (the big gap).** No Tooltip primitive exists; 71 of 89 components have zero hover help; ToolsPanel lists every tool with no description.
- Build one accessible `Tooltip` component (hover + keyboard focus, delay, escape-dismiss, aria-describedby).
- Add `description` metadata to every tool in the registry; ToolsPanel renders it on hover.
- Sweep: ToolsPanel, SettingsPanel/Modal, TrustPanel, InputBox toolbar, ModelSelector, StatusIndicator, DashboardPanel controls.
- Acceptance: every interactive control explains itself on hover AND keyboard focus.

**A2. Electron bump 28 → current stable.** Already an Aden-flagged manual step; doing it pre-tag is exactly the "major changes now" call. Full Jest + Playwright suites must pass; native module (better-sqlite3) rebuild verified.

**A3. First-run audit.** One-click install → FirstRunModal → first successful chat with zero manual config. Walk it, fix friction.

**A4. Installer verification.** Confirm per-user NSIS build installs and launches clean on a fresh Windows profile. (Code-signing decision = Aden's, costs money, not blocking.)

**Then:** tag **v1.1.0**.

## Phase B — Creator Studio (v1.2, branch `feat/creator-studio`, no auto-merge)

**B1. Cloud gateway.** ONE module all cloud calls route through. Per-provider toggles (default **OFF**) in WebServicesPanel; every call logged to the permission audit trail. Fully-private mode = switches off — structural, not a promise.

**B2. Images.** Hugging Face Inference API (FLUX.1-schnell) provider behind the gateway; extends the existing ImageGenerator component.

**B3. Video render.** New `media-studio` tool: ffmpeg slideshow render — stills + zoompan Ken Burns + drawtext beats + narration mux → MP4. **No Remotion in the product** (licence: free for individuals, paid when shipped in a distributed app). ffmpeg detected on PATH or user-pointed in settings.

**B4. Voice.** TTS provider(s) (ElevenLabs / HF) behind the same gateway; STT stays local Whisper.

**B5. Shared script format.** Beat-sheet JSON identical to the `scripture-stories` repo — that channel is the live proving ground; HomeBot productises what wins there.

## Phase C — Obsidian brain (privacy-native, no toggle needed)

**C1.** New `vault` tool: read/write/search markdown in the vault path (a Settings field). Local disk only; gated by the existing filesystem permission model.
**C2.** Creator Studio writes scripts/beat-sheets into the vault; vault becomes the brain-backup landing zone.
