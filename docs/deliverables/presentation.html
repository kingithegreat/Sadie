The Problem

Cloud AI Assistants Today

  • Require constant internet connectivity
  • Send all your data to external servers
  • No control over which AI models are used
  • Cannot access your local files or system
  • Subscription costs add up ($20+/month)

What Users Actually Need

  • AI that works offline and respects privacy
  • Real system access: files, terminal, email
  • Choice of AI models on their own hardware
  • A single app that replaces multiple tools
  • Zero recurring costs after installation
"What if your AI assistant ran entirely on your own computer, with full access to your files and tools, and never sent a byte of your data to the cloud?"

9-Layer Security Model

An AI assistant with system tool access demands rigorous safety. HomeBot uses defence-in-depth:

1Tool Allowlist — disabled tools cannot be registered or called
2Safety Rules — path whitelist for file tools, command blocklist for terminal
3API Allowlist — outbound HTTP restricted to listed hosts only
4SSRF Protection — blocks localhost, private IPs, non-HTTP schemes
5IPC Hardening — context isolation, no node integration, no webview
6Webhook Auth — 256-bit per-install secret for n8n communication
7Terminal Safety — catastrophic commands blocked + mandatory user confirmation
8Codebase Guards — read-only tools with binary/large file exclusion
9Recursion Cap — max 10 tool rounds prevents infinite LLM loops

Challenges & Lessons Learned

Challenges

  • LLM hallucination in tool calls — solved with deterministic routing for common intents and recursion caps
  • Ollama reliability — auto-restart heartbeat and model fallback on missing models
  • Electron security — balancing tool access with IPC isolation required careful preload API design
  • Context window limits on small models — adaptive context budgets based on model size

Lessons Learned

  • Typed IPC bridge investment paid off at scale — 60+ channels with zero runtime type errors
  • Iterative security was effective but a formal threat model earlier would have been more systematic
  • Deterministic routing before LLM routing dramatically improves response time and reliability
  • Tool registration pattern made adding new tools trivial — just a definition + handler
