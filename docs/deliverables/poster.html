Problem Statement

Cloud-based AI assistants require internet connectivity, send personal data to external servers, and offer no user control over the AI models or tool integrations. Users who value privacy, offline capability, or customisation have no viable desktop alternative that combines conversational AI with real system-level tool execution.

Project Objective

Design and build a fully local, privacy-first AI desktop assistant that runs open-source language models on the user's own hardware, provides 85+ system tools (file management, code execution, web search, email, calendar, RAG), and requires zero cloud dependencies for core functionality.

Methodology

Iterative Agile development over 13 weeks with continuous integration:

  • Weeks 1–3: Core architecture — Electron scaffold, IPC bridge, Ollama integration, message routing
  • Weeks 4–6: Tool ecosystem — 85+ tools across 10 categories, safety model (9 layers), permission system
  • Weeks 7–9: Advanced features — streaming UI, agentic loop, cloud LLM routing, RAG engine, automation center
  • Weeks 10–11: Polish — Quiz mode, image generation, UI redesign, one-click installer
  • Weeks 12–13: Standout features — Dashboard, voice conversation, screen capture, automation templates, rebrand to HomeBot

Testing Strategy

  • 131 test files across unit and integration levels
  • Jest + React Testing Library for component and logic unit tests
  • Playwright for full Electron end-to-end tests with isolated user profiles
  • Tests cover: streaming, retry/cancel flows, onboarding, permissions, tool safety, routing, persistence
  • TypeScript strict mode enforces type safety across all 241 source files

Key Design Decisions

  • Privacy-first: All AI inference runs locally via Ollama. No data leaves the machine unless the user explicitly configures a cloud provider.
  • Typed IPC bridge: The preload layer enforces a strict API surface between renderer and main process, eliminating direct Node.js access from the UI.
  • Deterministic routing: Regex-based intent detection handles common queries (weather, time, web search) without LLM overhead, falling back to streaming LLM for open-ended requests.
  • Agentic autonomy with limits: The LLM can chain tools across multiple rounds but is capped at 10 tool calls per turn with mandatory user confirmation for destructive actions.
  • Graceful degradation: Cloud and n8n services are optional. HomeBot operates fully on local Ollama, scaling up when additional services are available.

Results & Outcomes

  • Fully functional desktop AI assistant running 100% locally with no mandatory cloud dependencies
  • Sub-second response initiation for deterministic tool calls; streaming LLM responses begin within 1–3 seconds on consumer hardware
  • 85+ tools spanning filesystem, web, vision, code, communication, and RAG categories
  • 9-layer security model preventing SSRF, command injection, path traversal, and tool abuse
  • Cross-platform Electron build with NSIS installer for one-click Windows deployment
  • Premium dark UI with glassmorphism, 15+ CSS animations, and reduced-motion accessibility support
