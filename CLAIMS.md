**Integration notes — 2026-09-13, every scene image in one render must be the SAME real format (`media-visuals.ts`):** this was the actual cause of the red 2026-09-12 nightly. Scene files are all named `.png`, but the bytes were whatever the provider sent — Pollinations returns JPEG (`ffd8 ffe1`), while the local fallback plate is a genuine PNG (`8950 4e47`). The renderer feeds every scene to ONE ffmpeg concat demuxer, which probes the first file, commits to a single decoder, and silently drops every frame it cannot decode: `[mjpeg] No JPEG data found in image`, a 9.768s narration rendered as a 6.333s video, both streams truncated. **Correct file extensions do NOT fix this** — measured on the failing artifacts, mixed `jpg+jpg+png` with correct extensions still produced 6.333s while the same three images in one uniform format decoded cleanly.
